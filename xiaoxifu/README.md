# xiaoxifu — 小西西弗动量轮动策略(复现)

复现小西西弗(MatrixSpk)公众号三个「风险调整动量 + 定期轮动」策略。原文整理见本目录三个 md。

## 通用逻辑(`engine.py`)
- 风险调整动量 `Adj_Momentum = N日日收益均值 / sqrt(N日日收益方差)`(默认 N=20)。
- 每 K 天调仓(K=1 即每日):原始动量为正 → 按 Adj_Momentum 降序取前 L → 按 Adj_Momentum 归一化配权。
- 权重滞后 1 天(T 决策 T+1 执行,规避未来函数)。空仓机制:无正动量标的则持币。
- 指标:年化收益(几何)/ 年化波动 / 最大回撤 / 夏普 / 卡玛。
- 价格一律前复权(复权方式不影响收益率)。个股走本地 DuckDB;ETF 走 tushare `fund_daily+fund_adj`(在线)。
- **含手续费**:按每次调仓换手 `Σ|Δw|` 扣佣金 + 卖出印花税(个股佣金双边0.025%+印花0.05%,ETF佣金0.02%免印花),成本滞后1天。基准/等权为毛口径(被动无换手)。

## 三个策略
| 模块 | 标的池 | 调仓 | 基准 | 原文年化 | 本地复现(含费,2024起) |
|---|---|---|---|---|---|
| `leader_momentum.py` 龙头动量 | 22 只赛道龙头股 | 每 K=5 天取前 L=5 | 科创50ETF | >110% | ~102% |
| `allweather.py` 全天候 | 纳指/沪深300/黄金 3 ETF | 每日,正动量全取 | 沪深300ETF | 47.4% | ~39% |
| `industry.py` 行业动量 | 13 只行业 ETF | 每 K=5 天取前 L=5 | 科创50ETF | 35.8% | ~20% |
| `regime_combo.py` 牛熊切换 | 龙头↔全天候(MA30&MA60门控) | 见下 | — | — | ~112%,回撤减半 |

差异来自数据源(原文 Yahoo、本地 tushare)、回测终点(本地到最新)与部分 ETF 上市较晚导致早期缺数。

## 用法
```
python xiaoxifu/leader_momentum.py --N 20 --K 5 --L 5 --start 2024-01-01
python xiaoxifu/allweather.py --N 20
python xiaoxifu/industry.py --N 20 --K 5 --L 5
```

## 前端
webapp 菜单「小西西弗」(`#/xiaoxifu`),Tab 切换三个策略;每个 = 绩效卡 + 累计收益曲线 + 调仓动作表。
后端 `POST /api/xiaoxifu`(字段 `strategy`: leader|allweather|industry)复用本目录各模块 `to_payload`。

## 实验:行业动量「动态选池」与熊市证伪(scratchpad,未落地)

对「原文写死 13 只 ETF」的池子做过检验,结论是**池子选择几乎决定成败,而策略本身在熊市无 alpha**。

| 池子方案 | 2024起 年化/回撤 | 2023起(含熊市) 年化/回撤 |
|---|---|---|
| 原文写死 13 只 | 21% / 25% | 3.8% / 54% |
| 流动性池(**前视**,按期末成交额排) | 46% / 12% | 20% / 18% |
| 流动性池(**PIT**,每期按过去60日成交额现排) | 34% / 34% | **-2.8% / 64%** |

- **前视版 46% 是假的**:改成 point-in-time(只用调仓日当时已知的流动性)后 2024 段 46%→34%,回撤 12%→34%。低回撤是「事后只留赢家」造出来的。
- **牛市温和改善**:动态选池 21%→34%,但回撤没降,夏普仅 1.0,改善主要来自池子集中到强 beta 科技板块。
- **熊市彻底证伪**:PIT 动态池 2023起 -2.8%、回撤 64%,比写死 13 只还差 → 问题不在池子,在动量逻辑本身(急跌+快速轮动里被反复追高杀跌)。原文 35.8% 大半是选池幸存偏差 + 时段红利。

**应对思路**:熊市相对好识别,可在熊市**切到全天候策略**——全天候含黄金+跨资产分散,2023起回测年化仍 33.9%、回撤仅 13.9%,天然抗跌。即「牛市持龙头,跌破择时线切全天候」的市况分层,而非在单一策略里硬扛。

## 实验:市况分层(牛市持龙头 / 熊市切全天候)择时对比

信号滞后1天防前视,组合日收益 = 避险期取全天候、否则取龙头。三种择时开关对比(下表为**毛口径 gross**,择时横评时未扣费;落地的 `regime_combo.py` 已含费):

**2023起(含熊市)** — 纯龙头 年化108.7% / 回撤38.2% / 夏普2.51 / 卡玛2.84

| 择时开关 | 年化 | 回撤 | 夏普 | 卡玛 |
|---|---|---|---|---|
| 抱团度 crowding_di > 滚动分位0.7 | 105.1% | 32.3% | 2.79 | 3.26 |
| 沪深300 < MA60(走坏) | 83.8% | 16.7% | 2.48 | 5.02 |
| **沪深300 < MA30(走坏)** | **93.6%** | **16.0%** | **2.80** | **5.84** |

**2024起** — 纯龙头 年化105.3% / 回撤19.4% / 夏普2.46 / 卡玛5.43

| 择时开关 | 年化 | 回撤 | 夏普 | 卡玛 |
|---|---|---|---|---|
| 沪深300 < MA60 | 89.5% | 16.7% | 2.43 | 5.36 |
| **沪深300 < MA30** | **104.4%** | **16.0%** | **2.85** | **6.51** |

- **MA 择时完胜抱团度择时**。抱团度(residual-MI 系统性风险)不适合做指数级牛熊择时:它高位常出现在牛市抱团加速期,与实际下跌错配,避险 44~48% 太频繁,拖累收益却不降回撤(更宜用于逃顶/横截面降抱团暴露)。
- **已实现波动率分位** 比抱团度好(至少能降一点回撤),但仍输 MA30——波动率是同步/滞后指标(大跌时才飙,已在回撤里),价格破均线更早。故不值得复刻 RegimeFolio(arxiv 2510.14986)波动率状态层 + 板块ML + 均值方差那套重工程。

### 冠军:双均线 AND 门控

全部择时开关同口径横评,**最优 = 沪深300「MA30 且 MA60 同时走坏」才切全天候**(两条都跌破且下行):

| 方案 | 2023起 年化/回撤/夏普/卡玛 | 2024起 年化/回撤/夏普/卡玛 |
|---|---|---|
| 纯龙头 | 108.7 / 38.2 / 2.51 / 2.84 | 105.3 / 19.4 / 2.46 / 5.43 |
| 单条 MA30 走坏 | 93.6 / 16.0 / 2.80 / 5.84 | 104.4 / 16.0 / 2.85 / 6.51 |
| **MA30 且 MA60 均走坏(AND)** | **108.8 / 16.7 / 3.08 / 6.52** | **118.6 / 16.7 / 3.08 / 7.10** |
| MA30 或 MA60 走坏(OR) | 70.4 / 16.0 / 2.21 / 4.39 | 77.2 / 16.0 / 2.21 / 4.82 |
| 死叉 MA50<MA200 | 99.5 / 19.4 / 2.64 / 5.13 | 101.7 / 19.4 / 2.64 / 5.24 |
| 已实现波动率>分位0.7 | 97.8 / 25.1 / 2.57 / 3.89 | 88.0 / 18.4 / 2.51 / 4.79 |

- **AND 门控几乎零收益代价甚至增收**:2023 年化 108.8%(=纯龙头),2024 年化 118.6%(比纯龙头还高),同时回撤 38%→17% 砍半,夏普 3.08、卡玛 6.5~7.1。
- 关键:AND 要两条线**都**走坏才切,避险占比更低(38~47% vs 单条 53~59%),过滤掉「浅回调很快收复」的假信号,只在真正持续下行时离场——既躲大回撤又不被浅坑洗下车。
- OR 太敏感(67% 时间避险,收益腰斩);死叉 MA50/200 太慢,回撤没降。
- **落地规则:沪深300 收盘同时 < MA30 且 < MA60(且两均线下行)→ 持全天候,否则持龙头。**
