# 量化研究文档：首板小量信号 → 二板溢价预测

**版本**：v2 · 2026-05
**作者**：clay1wang
**状态**：研究阶段（非实盘）

---

## 1. 背景与动机

A 股打板派交易者的核心问题之一：**首板（首次涨停）信号出现后，哪些股票会在次日继续封板，并且第三日还能维持溢价？**

经验上，「缩量首板」相比「爆量首板」有更高的次日连板率（用户实测：缩量 24.9% vs 爆量 15.5%），但这只是一维统计。本研究试图用机器学习把多维信号（量价、资金、筹码、市场情绪）综合，给出对单只股票的概率预测，作为**人工筛选辅助工具**。

---

## 2. 研究目标

### 2.1 核心目标

构建一个二分类模型，对每个首板小量信号输出「成功概率」，使用户能从每天数十个候选中筛出 **Top 1-5%** 的高确信度股票供人工最终判断。

### 2.2 非目标

- ❌ 替代人工决策、自动下单
- ❌ 预测具体收益率
- ❌ 处理 T+1 一字板买不进等执行细节（由人工判断）
- ❌ 估算实盘策略收益曲线（由人工根据自身仓位策略评估）

---

## 3. 信号定义（Universe + Trigger）

### 3.1 Universe

A 股主板（沪 + 深），具体排除：
- 创业板（300xxx）
- 科创板（688xxx）
- 北交所（.BJ）
- ST / *ST 股票（按 stock_st 当日精确过滤）

理由：上述板块涨跌幅限制不同（20%）或交易规则差异，混入会污染样本。

### 3.2 信号触发（首板小量）

T 日满足以下条件即触发信号：

| 条件 | SQL |
|---|---|
| 当日涨停（U 类型） | `limit_list_d.limit_type = 'U'` |
| 首板（连续涨停 = 1） | `limit_list_d.limit_times = 1` |
| 非一字板 | `daily.high > daily.low` |
| 小量（vol/ma5 < 1.4） | `daily.vol / AVG(vol).T-5..T-1 < 1.4` |
| 信号日非 ST | `LEFT JOIN stock_st ... IS NULL` |

**关键阈值**：`vol/ma5 < 1.4` 是当前选定值。`< 1.4` 是「非爆量」的近似边界（爆量定义业内通常 ≥ 2x），含轻缩量到平量。该阈值的稳健性将在 M3 阶段做敏感性检验（1.2 / 1.4 / 1.6）。

### 3.3 信号覆盖

- 时间区间：2020-01-02 起（受 `limit_list_d` 表起始日期限制）
- 信号数：~21,700（截至 2026-05）
- 日均信号数：约 14 个（不均匀，牛市更密集）

## 4. 标签定义（Label）

### 4.1 复合标签（v2）

```
label = (T+1 pct_chg ≥ 9.8) AND (T+2 pct_chg > 0)
```

含义：T+1 日股票涨停（达成连板），且 T+2 日收盘价 > T+1 日收盘价（次日仍有溢价，不破板）。

### 4.2 进出场假设

| 时点 | 动作 |
|---|---|
| T 日盘后 | 模型扫描首板信号，输出 Top N |
| T+1 开盘 | 假设按开盘价买入（执行细节由用户人工判断） |
| T+2 收盘 | 假设按收盘价卖出 |

注：模型不关心实盘是否买得到（一字板等问题由用户控制）。

### 4.3 历史标签分布

- **正例率**：~12.4%（21,666 个有完整 T+1/T+2 数据的信号中，2,616 个 label=1）
- **分量分布**：
  - T+1 涨停率：20.12%
  - T+1 涨停子集中 T+2 溢价率：61.73%
  - 联合复合率 = 20.12% × 61.73% ≈ 12.4% ✅

## 6. 评估标准

### 6.1 模型层

- AUC-ROC（整体排序能力）
- KS（正负样本分离度）
- **Top N% 胜率 + Lift**（核心指标，对应实际使用场景）
  - Top 1%：人工筛选「最自信推荐」的命中率
  - Top 5%：日常推荐池
- 分月 OOS AUC（M3：稳定性检验）
- 校准曲线（M3：概率诚实度）

### 6.2 v2 模型基线对比（2024-2026 测试集）

| 指标 | M3 基线（27 特征） | M4 调整后（25 特征 + 调参） |
|---|---|---|
| AUC | 0.5870 | **0.5961** (+0.009) |
| KS | 0.4062 | 0.4120 |
| 基准胜率 | 12.42% | 12.42% |
| Top 1% 胜率 | 26.04% (2.10x) | 22.92% (1.85x) |
| Top 5% 胜率 | 19.67% (1.58x) | **19.88%** (1.60x) |
| Top 10% 胜率 | 18.12% (1.46x) | **18.94%** (1.53x) |
| best_iter | 104 | 153（早停问题已解决） |

M4 主要提升来源：参数调优（min_child_weight=15, n=650, lr=0.037, early_stop=80）；
3 个新加市场状态特征贡献偏小（`market_2lb_rate_ma5` SHAP 排倒数）。

### 6.3 输出层（M5 已实现）

`ml_score_v2.py` 输出 HTML 报告，包含：
- 市场状态横幅（自动判断趋势市/题材市/震荡市 + 文字警示）
- 市场指标小卡（最高连板/1板数/2板数/3板数/晋级率/距高点）
- 历史胜率参考条
- Top N 候选总表（含建议仓位，按排名+市场状态自动调整）
- 每只票 SHAP 因子分解卡片（中文因子名 + 数值 + SHAP 贡献）

### 6.4 实盘可执行性回测结论（2024-01 ~ 2026-05，市场状态过滤后 292 个出手日）

机械执行三种 T+2 卖出策略，**Top 2 × 10% 仓位**，整体均亏损：

| 卖出策略 | 整体胜率 | 累计 | 最大回撤 |
|---|---|---|---|
| A 一律开盘卖 | 36.83% | -75.28% | -76.36% |
| B 高开开盘卖否则收盘卖 | 42.51% | -45.40% | -49.40% |
| C 一律收盘卖 | 40.28% | -72.16% | -76.14% |

**但分量诊断揭示了真信号**：

| T+2 状态 | 占比 | 胜率 | 平均收益 |
|---|---|---|---|
| **T+2 高开** | 35-38% | **69-76%** | **+4.85% ~ +5.13%** |
| T+2 不高开 | 62-65% | 18-29% | -3.4% ~ -4.9% |

**结论**：
- 模型 Top N + T+2 高开 = 强 alpha 子集（胜率 70%+，单笔 +5%）
- T+2 不高开 60% 占比拖累整体到亏损
- 机械规则无法事前区分 T+2 是否会高开
- **必须依赖人工竞价判断**（诱空假摔识别 / 主力意图）才能选择性进入 T+2 不高开的反转机会
- 项目定位回归初心：**人工筛选辅助工具，非机械执行系统**

## 7. 时序切分与训练

### 7.1 当前切分

- 训练集：信号日 ≤ 2023-12-31（12,003 条）
- 测试集：信号日 ≥ 2024-01-01（9,663 条）

**重要**：测试集是严格 Out-of-Sample，训练时模型完全没见过 2024+ 数据。

### 7.2 模型选择

XGBoost。已对照验证：
- LightGBM AUC 0.583（默认参数早停异常，未细调）
- LogReg AUC 0.586（线性基线）
- XGBoost AUC 0.587（v2）/ 0.609（v1，旧 label）

非线性增益较小，XGBoost 是合理选择。

### 7.3 M3 已完成的验证

- ✅ 跨年度信号稳定性（2020-2026 base rate 稳定 10.6-13.7%）
- ✅ 分月 OOS AUC（均值 0.588，2025Q3 是真实失效期 AUC ~0.50）
- ✅ 多种子稳定性（5 seed AUC std=0.0023，模型完全可复现）
- ✅ 校准曲线（绝对值偏离大但单调递增 → ranking 有效，不影响 Top N 用法）
- ✅ 阈值敏感性（vol/ma5 < 1.4 是真实甜区，相邻阈值平滑过渡）
- ✅ 多维分桶（黄金组合 lift 1.68x：净流出+强封单）
- ✅ Walk-forward 季度滚动（14 季度 78% 有正 alpha）
- ✅ Optuna 超参搜索（提升 +0.83pp，已采纳进 M4）

### 7.4 已知失效场景

**2025Q3（指数突破压力位 + 趋势市）**
- 模型 AUC 跌至 0.48-0.55（接近随机）
- `market_2lb_rate_ma5` 跌至 ~0.15（连板生态弱）
- 用户经验：趋势市资金流向机构票，连板溢价被压缩
- 应对：`ml_score_v2.py` 自动检测并显示警示，建议降仓 30-40% 或空仓

## 8. 风险与限制

### 8.1 数据风险

- ❌ Tushare daily 表是**不复权**口径（已确认，影响有限因为特征均为比例类）
- ⚠️ stock_meta.name 是当前快照（已用 limit_list_d.name 兜底）
- ⚠️ ths_member 概念成分股是当前快照（概念特征已删，影响消除）

### 8.2 标签风险

- 复合 label 牺牲了样本量（正例从 ~20% 降到 12%）
- T+1 一字板未排除：T+1 一字板时 close = open × 1.1，T+2 即使大跌仍可能算 label=1（有偏向乐观）

### 8.3 信号风险

- vol/ma5 < 1.4 阈值未做正式稳健性测试
- 「缩量首板」假设本身基于近期市场结构，**风格漂移可能使其失效**

### 8.4 使用风险

- 模型 Top 5% 绝对 label 胜率仅 19.88%，**用户必须叠加人工判断**
- **机械执行 Top 2 在 2024-01 ~ 2026-05 全亏损**（A/B/C 三种卖法均 -45% ~ -75%）
- 真实可获取的 alpha 在 T+2 高开子集（占比 35-40%，胜率 70%+，单笔 +5%）
- 但**事前无法判断 T+2 会否高开**，必须 T+2 早盘人工观察竞价 + 分时
- 历史回测胜率 ≠ 未来胜率
- 模型存在月度级失效窗口（2025Q3 连续 4 个月 AUC < 0.55）

### 8.5 工具定位（重要）

`ml_score_v2.py` **不是**自动交易系统，**是**：
- 每日盘后从 100+ 首板小量信号缩到 Top 10 候选
- 提供因子解释 + 仓位建议 + 市场状态预警
- 节省用户 80% 的初筛人工时间

用户工作流：
1. 跑 `ml_score_v2.py` 看 HTML
2. 检查市场状态横幅（连板生态弱 → 直接空仓）
3. 健康市场：从 Top 10 人工再筛 1-2 只
4. T+1 开盘买（按个人策略）
5. T+2 早盘竞价主观决策（高开秒卖 / 低开看分时判断诱空）
